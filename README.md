# ✦ AftabAura

A frontend-only e-commerce website built with React.

## Features
- Home, Products, Product Detail and Cart pages
- Signup / Login with unique usernames
- Per-user cart (each user sees only their own items)
- Product search and category filter
- Protected cart route
- Dark espresso + saffron theme

## Tech Stack
- React 18 (JavaScript)
- React Router DOM
- Context API (Auth + Cart)
- Tailwind CSS v4
- Vite

## Getting Started
```bash
npm install
npm run dev
```
Open http://localhost:5173

## Build
```bash
npm run build
```

## Note
This is a frontend demo. Users and carts are stored in the browser's `localStorage`, and passwords are not hashed. A real app needs a backend.
